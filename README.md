# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Navigation** - Smooth scrolling between sections
- **Project Showcase** - Display your projects in an attractive grid layout
- **Contact Form** - Allow visitors to get in touch
- **Modern Styling** - Beautiful gradient colors and smooth animations

## File Structure

```
portfolio-website/
├── index.html       # Main HTML file
├── css/
│   └── styles.css   # Stylesheet
├── js/
│   └── script.js    # JavaScript functionality
├── images/          # Place your images here
└── README.md        # This file
```

## Getting Started

1. Clone or download this project
2. Open `index.html` in your web browser
3. Customize the content with your information:
   - Update your name and bio in the About section
   - Add your projects in the Projects section
   - Customize colors and fonts in `css/styles.css`

## Customization

### Edit Your Information
- Open `index.html` and update the content in each section
- Replace placeholder text with your own information

### Change Colors
- Open `css/styles.css`
- Find the color values (like `#667eea`) and replace with your preferred colors
- The main colors are defined in the gradient: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`

### Add More Sections
- Copy the structure of existing sections in `index.html`
- Add corresponding styles in `css/styles.css`
